## Work done: uv workflow, stable pagination, column sorting, status filters

The user requested uv migration, sorting all table columns except Description,
and filtering by remote status. They confirmed the existing pagination jump to
the top was unwanted and asked to remain near the footer controls.

### Changes

- Kept the existing uv manifest/lockfile and zero runtime dependencies. Added
  `.python-version` selecting 3.12, changed the script shebang to uv, and made
  `uv sync --locked` / `uv run` the documented setup, runtime, and test workflow.
  Lock validation passes without needing dependency/version changes.
- Added Name, Path, and Remote status header buttons with natural numeric,
  case-insensitive ascending/descending sorting. Status uses the displayed
  badge label, with name/path tie-breakers. Sorting affects the complete
  collection before slicing pages and resets to page 1.
- Cards/rows receive identical escaped metadata and are paired in one client
  collection, so search, exact status filtering, ordering, and pagination stay
  in sync across view switches. Sorting/filtering reset on reload; existing
  view/page-size preferences persist, including a fix for the All preference.
- Added the labeled status dropdown for all eight git states, an empty-results
  message, accessible sort direction/current-page metadata, and live counts.
  Global shortcuts ignore inputs/selects so native dropdown keys still work.
- Pagination records its container's viewport position before rendering and
  scrolls by the change afterward, preserving footer position across unequal
  pages. Focus moves to the regenerated current-page button without scrolling.
  Native viewport limits apply when the new document is shorter than a screen.
- Allowed the status toolbar and pagination buttons to wrap on narrow screens.
- Added empty root `AGENTS.md` per user instructions; updated README,
  ARCHITECTURE, and PROMPT. No environment-variable or gitignore changes needed;
  generated fixtures stay outside the checkout and `.venv` is already ignored.
